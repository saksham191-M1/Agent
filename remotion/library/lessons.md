# AI Director Lessons

* **[motion] SaaS Aesthetic (Transitions):** Avoid flashy scene transitions like wipes or blurs. Use hard cuts (`none`) or very fast fades. Let the internal UI elements animate smoothly using spring physics instead.
* **[motion] SaaS Aesthetic (Audio):** Avoid heavy, generic sound effects (whooshes, loud impacts). Use premium, subtle UI sounds (soft clicks, ticks, soft pops) and modern, upbeat electronic/lo-fi music beds.
