# Engine toolkit

- `@remotion/three`: depth-heavy device scenes when a job requires 3D.
- `@remotion/lottie`: import existing brand motion assets without changing the engine.
- `@remotion/noise`: organic gradient and atmosphere motion.
- `@remotion/motion-blur`: readable speed ramps and whip transitions.
- `@remotion/shapes`: reusable geometric primitives.
- `@remotion/paths`: animated paths, cursors, and data lines.
- `@remotion/transitions`: beat-aware scene transitions.
- `@remotion/captions`: caption data and rendering utilities.
- `@remotion/google-fonts`: deterministic real-font loading.
- `@remotion/media`: shared media primitives for job assets.
- `ffmpeg-static` and `ffprobe-static`: portable delivery-media QA independent of host binaries.
