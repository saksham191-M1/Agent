# Creative reference shelf

Files in this folder are **format-neutral creative references for AI video generation**.

They can guide:

- pacing and visual density
- camera movement and framing
- character or persona treatment
- transitions, color, typography, and sound rhythm

They do not force every result to be a product advertisement. The requested script decides the format: ad, story, POV,
comedy, character piece, demo, cinematic sequence, explainer, or another suitable structure. An advertisement should be
chosen only when the brief, product, offer, or explicit request supports it.

Use the references as inspiration for visual language and production choices. Do not copy a creator's identity, dialogue,
story, or exact shot sequence.
